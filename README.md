# 三国麻雀（sanguo-riichi）

日麻（雀魂基础规则）+ 三国杀式武将技能，前后端分离的联机麻将。
规则引擎基于 [summivox/riichi-core](https://github.com/summivox/riichi-core) 重构：不重写内核，
把它拆成「纯数据 + 纯函数 + 事件流」，外面包一层技能钩子，上层接网络。

## 技术栈

| 层 | 选型 |
|---|---|
| 规则内核 | TypeScript 纯函数（从 riichi-core 迁移） |
| 前端 | Vue 3 + Vite（只发命令、收广播，不做判定） |
| 后端 | Node + `ws`（权威服务器） |
| 测试 | Vitest |

## 目录结构

```
riichi-sanguo/
├─ packages/core/     # 纯规则引擎 + 技能系统（前后端共享，零依赖）
│  ├─ src/types.ts    #   牌/面子/状态类型、确定性洗牌
│  ├─ src/engine.ts   #   step(state, action) reducer + 技能调度 + 飞人规则
│  ├─ src/scoring.ts  #   点数计算（占位参考，M2 整体换 riichi-core Scoring）
│  ├─ src/skills.ts   # ★ 技能钩子 + 三个示例技能
│  ├─ src/generals.ts #   武将数据（每将一套技能）
│  └─ test/           #   技能边界 + 引擎集成测试
├─ packages/shared/   # 前后端协议（ClientMsg / ServerMsg，M2 上 zod）
├─ packages/server/   # 权威服务器：房间、WS、AI 托管、断线快照
└─ packages/client/   # Vue3 前端：加入房间、看手牌、摸打、事件日志
```

## 快速开始

```bash
npm install            # 根目录，workspaces 会装齐所有包
npm run dev:server     # ws://localhost:8787
npm run dev:client     # 浏览器开 http://localhost:5173
npm test               # 跑核心引擎 + 技能单测
npm run typecheck      # 全仓 TS 类型检查
```

玩法：开浏览器标签，先点「**连接**」建立 WebSocket，再「**刷新列表**」看有哪些房，最后填昵称/房间号/密码点「**入座**」。

**首个加入者=房主**，房主可：
- 勾选规则（如「切上满贯」）
- 设置**房间密码**（其他人加入时需输入；列表里显示 🔒）
- 点「补入 AI」占位（想 1 真人 + 3 AI 就连点 3 次）
- 点「开局」用当前人数开局（剩余空位自动补 AI）
- 满 4 人自动开局

支持任意组合：**1 真人 + 3 AI / 2 + 2 / 3 + 1 / 4 真人**（实测均已验证）。
轮到你时**自动摸牌**，点手牌即打；别人打牌后，若你能吃/碰/杠/荣和（含抢杠、自摸、暗杠/加杠），按钮自动出现——**思考时限 25 秒 + 10 秒补时**，超时自动代打。

## 视觉设计（竹简水墨）

**设计理念**：不取霓虹与玻璃拟态那套"AI 风"，走竹简水墨——麻将本身就是古物，把质感还给牌桌。

| 维度 | 做法 |
|---|---|
| **五色** | 墨 `#17150f` / 宣纸 `#e9e2d3` / 竹青 `#4b6b52` / 朱砂 `#a4352c` / 黄铜 `#c9a227`（无蓝紫渐变） |
| **字体** | 衬线（Noto Serif SC / 宋体），标题加宽字距，数值用等宽数字 |
| **布局** | **牌桌是主角**：四家方位 + 中央场（局数/本场/供托）；UI 从属，不做面板卡片堆叠 |
| **牌面** | 素材只提供**图案层**，**牌底由本作渲染**（象牙白渐变 + 内阴影 + 投影）→ 可自由换肤 |
| **交互** | 悬停抬牌、荣和按钮作朱砂印章、摸到的牌与手牌分隔、立直宣言牌横置 |
| **牌桌** | 四家方位；**弃牌环绕中央场**（对家上 / 上家左 / 下家右 / 自己下）；副露完整展开、**被鸣的牌横置**；对手显示手牌背面（张数由事件广播，精确） |
| **结算** | 和牌/流局弹**卷轴面板**：役种标签、番符、点数转移明细、**数字滚动**的各家增减、本局触发的技能；**役满**时卷轴镀铜并盖朱砂「役满」印；底部「收卷」关闭 |
| **音效** | **Web Audio 现场合成**（无音频素材）：出牌=木牌落桌、吃碰杠=实击、立直=铃、和牌=磬、役满=层叠泛音、流局=低钟；顶栏可开关 |

## 录像回放

引擎是「纯函数 + action 驱动」，因此**只需记录动作序列即可完整重放**（无需录屏、体积极小）：

| 环节 | 实现 |
|---|---|
| **录制** | 服务器按局归档 `{ round, dealer, actions[] }`（仅记录被引擎接受的动作）+ 开局元信息（座位/武将/规则/种子） |
| **获取** | 客户端 `{t:'replay'}` → 服务器回 `ReplayData`（含已结束的局与进行中的局） |
| **重放** | `core/src/replay.ts` 的 `replayGame()`：从同一种子重建初始状态，按序 `step()` 推进，逐步回调状态与事件 |
| **回放界面** | 客户端**本地重放**（无需再联网）：播放/暂停、上一步/下一步、跳到开头/末尾、0.5×–4× 倍速、步数进度；牌桌复用同一渲染（四家手牌全可见，便于复盘） |

**正确性验证**（服务端录制 → 客户端重放 → 对比）：
```
服务器：分数 30000/30000/30000/30000｜弃牌 6/6/6/5
录像：1 局 / 69 个动作
重放：69 步｜分数 30000/30000/30000/30000｜弃牌 6/6/6/5
分数复现 ✅　弃牌复现 ✅　手牌张数复现 ✅
```
另有单测：AI 对局 449 步**逐步指纹比对**（分数/手牌/弃牌/立直/一发/行动者/牌山/巡目）完全一致 + 同一录像重放两次结果一致（确定性）。

### 技能能力（声明式，引擎统一处理）

| 能力 | 作用 | 启用者 |
|---|---|---|
| `blocksCalls` | 你打出的牌不可被吃/碰/杠 | 夏侯惇 · 刚烈 |
| `locksRiichi` | 先制立直后封锁他人立直 | 袁术 · 妄尊 |
| `suppressesRyukyoku` | 听牌时接管流局罚符结算 | 董卓 · 暴敛 |
| `forceWin` | 无役亦可和牌（0 番照和，宝牌番数照算） | 袁绍 · 乱击 |
| `countsAsYaku` | 技能给出的番数可充当「和牌资格」（无役时靠它成立） | **暂未启用**，需要时在武将数据里标注 |

**技能钩子**：`onAgaru`（自己和牌改番/加钱）、`onOtherAgaru`（他人和牌收费）、`onRyukyoku`（流局）、`onCall`（他人副露收费）、`onPay`（付点时减额）。

> 规则边界：**「役」= 和牌资格，「番」= 役的价值**。宝牌/赤宝牌/里宝牌计入番数但不构成役；
> 技能默认只能改番，若要突破「必须有役」需显式声明 `forceWin` 或 `countsAsYaku`。

### 生产部署

| 部分 | 做法 |
|---|---|
| **服务端** | 用 pm2 / systemd 常驻 `npx tsx packages/server/src/index.ts`；端口用环境变量 `PORT`（默认 8787） |
| **前端** | `npm run build -w @sanguo/client` → 产物在 `packages/client/dist`，交给 Nginx / CDN |
| **前端连哪台服务器** | 复制 `packages/client/.env.example` 为 `.env.production`，设 `VITE_WS_URL=wss://your.domain/ws`（不设则默认 `ws://<当前域名>:8787`） |
| **WebSocket 反代（Nginx）** | 见下 |

```nginx
location /ws {
  proxy_pass http://127.0.0.1:8787;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
}
```

> 服务器是**内存态房间制**：单进程即可跑。若要横向扩展，需按 roomId 把连接路由到固定实例（一致性哈希）。
> 录像目前只在内存保留最近一局；`Room.replay()` 返回纯 JSON，可定期落盘做持久化。

## 武将技能

| 武将 | 阵营 | 技能 | 效果 | 触发点 |
|---|---|---|---|---|
| 关羽 | 蜀 | 武圣 | 胡牌时每个**万字面子** +1 番 | 和牌 |
| 沮授 | 群 | 渐营 | 当你**连续三张打出一类牌**（同一花色或字牌）时，和牌 **+1 番，可累计**（滑动窗口；**被鸣走的牌不算**） | 和牌 |
| 司马懿 | 魏 | 忍戒 | 荒牌流局时其余三家各付你 **2000** 点 | 流局 |
| 张辽 | 魏 | 突袭 | 有人吃/碰/杠时，**该玩家付你 500 点** | 他人副露 |
| 袁术 | 群 | 妄尊 | 你**先制立直**（场上第一个）时他人无法立直；此后**其他人**和牌时该和牌者付你 **1000** 点（你自己和牌不触发，番数照常结算） | 立直 / 他人和牌 |
| 董卓 | 群 | 暴敛 | 和牌时按已打出牌数改番（≤8 张 **+3**；9~12 张 **+1**；>12 张 **-2**，下限 0）。流局时：**你听牌** → 不管别人听不听、**所有人各付你 2000**（且其他听牌者收不到罚符）；**你未听牌** → 其他人正常结算，你额外付 2000 给听牌者 | 和牌 / 流局 |
| 孙权 | 吴 | 制衡 | 和牌手牌含**索子一气通贯**（123s+456s+789s）时 +3 番 | 和牌 |
| 陈到 | 蜀 | 往烈 | 本局中你每有 **1 张牌被鸣走**（被吃/碰/杠），你**付出点数时减 1000**（最低 0） | 全局（付点时） |
| 夏侯惇 | 魏 | 刚烈 | 你打出的牌**不可被吃/碰/杠** | 全局 |

技能实现方式：引擎在结算点调用钩子（`onAgaru` / `onOtherAgaru` / `onRyukyoku` / `onCall` / `onPay`），技能可改番符、追加或修改点棒转移，或声明规则修饰（`blocksCalls` 刚烈、`locksRiichi` 妄尊、`suppressesRyukyoku` 暴敛）。**所有技能状态都在单局范围**（`log` 每局重置）。加新武将只需写 `skills.ts` 里的 `Skill` 对象 + 在 `generals.ts` 注册。

## 架构原则

1. **单一权威源**：服务器只跑一份 core 引擎，客户端只发命令、只收广播 → 防作弊、可回放。
2. **纯函数内核**：`step(state, action) → { nextState, effects }`，技能就是包在外面的钩子，不污染核心。
3. **协议先行**：所有跨端消息有类型定义（M2 上 zod 做运行时校验 + 版本号）。
4. **飞人规则（雀魂）**：结算后有人点数 < 0 立即终局，照常结算（`reason = 'tobi'`）。
5. **信息隔离**：手牌/牌山不下发他人；`targetSeat` 事件只单播给对应座位。
